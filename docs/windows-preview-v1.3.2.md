# V1.3.2 Windows 一键更新

继续使用原固定测试目录，不用下载ZIP，不用初始化或重新安装依赖。

1. 在原预览服务器黑色窗口按 `Ctrl+C`，关闭旧预览。
2. 双击原固定目录中的 `03-update.cmd`，等待成功；仍获取 `test/vi-v1.3.0`。若提示本地修改或分叉，停止并保留提示，不要强制覆盖或删除文件。
3. 双击 `02-start.cmd`，打开 http://localhost:3000 ，刷新确认页脚 v1.3.2。
4. 分别查看商场店与八廓街店，确认门头、入口和陈列完整。点击各店照片检查完整比例大图及关闭，手机检查横滑切店与上下滚动，再回归7件290元清单和保存。

iPhone与电脑连接同一Wi-Fi，使用启动窗口列出的电脑局域网地址；手机不要用localhost。原生分享依浏览器和安全上下文而定，原长按保存回退保留。

需要恢复时先关闭服务器，运行 `04-recover.cmd`；它在独立恢复分支打开本工具本次更新前版本，新测试分支保留。`05-return-test.cmd` 返回测试分支。一键工具及安全检查没有修改，仍不强制覆盖本地内容、不推送、不部署。
