# V1.4.1 轻水印优化版：报告与Windows更新

日期：2026-11-22；基线e7f8a6a（V1.4.1），独立分支`test/admin-v1.4.1-soft-watermark`。
软件版本仍V1.4.1，后台标记“轻水印优化版”，修订`20261122-admin-1.4.1-soft-watermark`。

## 修改原因与实际变化

原后台照片配方继承了60%透明度、较大的文字和反差描边；清单背景则先铺满斜向图案，再遮盖文字。后者难以可靠保护所有文字边缘、正文留白和二维码周围空间。

本轮将策略分开：

- **后台新上传/重新生成的照片**：10%透明度；字号比例由2.5%宽度降至1.8%；浅灰文字，无反差描边；4组分布位置更靠两侧、纵向更疏，避开中间主体。“扎西德勒鸭”与两个真实客服微信号交替出现。文字从全局品牌/客服配置读取，参数统一放在admin/watermark.mjs；不通过AI修改实物。
- **顾客测试页导出清单**：完全取消斜向背景水印，不再加载额外清单水印图。保留米白底、原Logo/二维码落款、客服微信、双门店、名称/价格/数量/合计和原有分享保存功能。二维码及其留白不加任何浮层、描边或重新绘制。
- 商品照片自身已嵌入的品牌标识仍留在商品缩略图内，清单正文、价格、客服和二维码区域不叠加水印。

## 原图与资料安全

- 仍从无水印原始文件生成独立衍生资产，不改原始文件、颜色、造型、材质或细节；压缩/尺寸策略沿用原功能。
- 新配方标记`distributed-brand-v2-soft`。继续接受旧角落图和60%分布式登记、旧资料/历史快照/完整ZIP；不在启动时强制迁移。
- 在“发布前检查”点 **备份并优化照片水印**，确认后先生成完整ZIP，再处理当前商品关联的旧图片（含回收站关联），最终一次切换引用。旧原图、旧展示图、旧关联历史全部保留；备份或生成失败不切换。
- 相同原图和相同配方复用，不重复叠加；已优化再次操作不新增资料版本。未引用的旧照片继续保留在照片库/备份，今后重新关联时可再次确认优化。
- **现有顾客端内置商品照片、品牌素材及其历史水印本轮没有重制**，它们属于原先受保护的静态测试素材。照片对比图展示后台新配方实际作用于原始实拍的效果；后台资料仍不自动同步到顾客网站。没有原图时不会拿旧水印图继续叠加处理。
- 退回旧程序前需先备份并恢复旧资料/图片基线；旧程序不一定理解新配方，不能同时混用两版后台。

## 测试结果

- `npm run check`：**97/97自动测试通过**，发布保护校验及本地构建成功。
- 新增测试：清单背景只进行一次不透明米白填充，零水印文字/图片/旋转；即使传入旧图案设置也不绘制。照片配方透明度8%～12%、小字、灰色、避开中央、两个真实客服、无描边；实际文字像素存在，未压缩合成像素干扰不超过10%理论上限。60%旧登记备份后从原图优化、原图哈希不变、旧资产保留、重复优化无变化。
- 原图保护、完整ZIP恢复、款式/排序/回收站、重启、Windows可写句柄刷新、文件写入失败保护和官方WASM回退测试继续通过。
- 使用3张真实蘑菇包私有原图生成优化前后衍生图，读取前后SHA-256相同；没有公开原图。
- 浏览器生成真实7件商品/290元清单：优化后导出画布旋转0次，半透明文字0次，半透明叠加图片0次；名称、价格、数量、合计及双客服均保留。
- 二维码实际解码：两张原始客服码、优化前清单、优化后清单均解码为同一组真实微信链接。留白完整保留，并实测两码四边合计超过1万纯白像素、连续11px纯白检查带（靠近码边的缩放抗锯齿不算叠加水印）；输出图片不重绘二维码。
- 7个浏览器回归脚本全部通过：V1.4.1后台、旧后台、照片流程、290元清单及图片失败回退、移动分享/长按保存、三款实拍、网页/离线双客服二维码。实际二维码解码也覆盖网页、离线及既有品牌照片。Windows真实安装/显示、微信/手机原生分享仍需真机验收，模拟测试不等同于用户电脑验收。

## Windows简明更新

1. 关闭旧07后台窗口；保留旧文件夹，建议先下载完整ZIP备份到其他磁盘。
2. [下载新测试分支ZIP](https://github.com/balabala555/zangdi-wenchuang-catalog/archive/refs/heads/test/admin-v1.4.1-soft-watermark.zip)，全部解压到新文件夹，不覆盖旧项目。
3. 双击新目录 **07-admin.cmd**，核对顶部“V1.4.1 · 轻水印优化版”和原有商品。私有商品库路径仍为`%LOCALAPPDATA%\ZangdiCatalog\merchant-data`，不重新初始化、不手工修改资料文件。
4. 新上传图自动使用轻水印。已有后台图片：点 **发布前检查 → 备份并优化照片水印**，确认后等待完成，再预览款式照片。优化前完整ZIP可在备份与恢复下载。
5. 如需验收清单，关闭旧顾客测试服务后运行新目录 **02-start.cmd**，在本地顾客测试页生成清单。不要使用03切换原稳定更新通道；不需要上传到公网。

后台商品和顾客测试页仍分离，保存不发布、不自动同步。旧资料/原图/历史文件不会清空；文件会因保留旧版本而增加，请留足本地空间并将备份另存外置磁盘。

没有新依赖或费用；main、正式网站、原V1.4.1分支不更新，不创建PR、不合并、不开放发布功能。
