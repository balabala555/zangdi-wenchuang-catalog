# V1.3.1 Windows 一键更新

继续使用电脑中原来的固定测试目录 `%USERPROFILE%\zangdi-preview`（例如 `C:\Users\ytb\zangdi-preview`）。不必下载新ZIP，不必重新初始化，不必安装依赖或运行sharp。

每完成一步再继续：

1. 到正在运行网站的黑色窗口，按 `Ctrl+C` 关闭预览。
2. 在原固定测试目录双击 `03-update.cmd`，等待更新成功。仍然获取 `test/vi-v1.3.0` 分支；若提示本地修改、目录/远程不匹配或分叉，保留提示并停止，不要删除文件或强制覆盖。
3. 双击同目录的 `02-start.cmd`，浏览器打开 http://localhost:3000 ，刷新并确认页脚 `v1.3.1`。
4. 首页默认检查绿色招牌、白鸭的八廓商场店，再切换到八廓街店。按蘑菇包2个、软萌小羊3个、彩虹小羊2个检查：共7件、290元，弹窗和PNG均应显示三种实拍图片。

iPhone与电脑保持同一Wi-Fi，使用启动窗口显示的电脑局域网地址访问；手机不要使用localhost。检查保存到相册及分享；普通局域网HTTP上原生分享受浏览器安全条件限制时，使用原有长按保存方式。

需要恢复时先关闭预览，再运行 `04-recover.cmd`；它在独立恢复分支打开这次更新前的版本，保留新测试分支。`05-return-test.cmd` 返回测试分支。原工具和安全条件未改：干净工作区、限定仓库/测试分支、只快进、更新前建立恢复点，不推送、不部署。

初次使用者仍可按 [首次配置指南](windows-preview-v1.3.0.md) 操作；已有固定目录的用户只执行上面的更新步骤。
