# V1.3.3 Windows更新修复交付报告

2026-11-21，继续`test/vi-v1.3.0`，基线V1.3.2 `cdcad694b613dbbc8cbb475faf4820fcd5dec297`，VI保持1.1。最终提交见聊天交付及测试分支最新提交；main和正式网站不操作。

## 根因和修复

旧脚本把所有目录都当Git仓库，ZIP没有.git，必然在rev-parse失败；端口检测也把任意3000监听者当旧预览。这两个问题与重启电脑无关。

- ZIP检测：新版03或一次性迁移包可识别ZIP，备份原文件夹，在独立固定目录克隆指定测试分支并运行版本/素材保护检查。旧目录不覆盖、不删除。目标非空则选择独立目录或停止，已有标准Git目录仍拒绝覆盖本地修改。
- 提供小型迁移ZIP：只有中文CMD入口、3份Node辅助脚本、说明及SHA256清单。无需重新下载完整项目ZIP后复制文件。Windows内置PowerShell只用于原生文件夹选择器；Node、Git、PowerShell及本地技术均免费，无需安装付费插件。
- Git更新只快进，更新前完整文件快照及Git bundle、备份分支和恢复记录，临时候选副本先运行真实版本保护门槛。失败不强制重置；04在独立目录恢复，即使当前目录已有个人修改也不覆盖它们。
- 本地管理接口默认关闭；只有02/03启动的子服务启用随机令牌。仅本机、有效令牌且无跨站Origin可请求关闭。元数据在用户临时目录，不进项目、不进Git、不向网页暴露令牌。旧PID不用于杀进程；已关闭/重启后的记录不阻止更新。普通无关服务不结束，启动自动选择空闲端口。
- 03更新后显示当前版本、提交、实际目录、备份路径及结果，并自动启动/打开网站。02重复打开时复用正确版本服务。05返回逻辑保留测试分支，不切换main。
- 原V1.3.2界面、商品资料/价格、全幅门店与商品水印图、清单/290元/保存功能完全保留。

## 备份边界

文件快照包括未跟踪和忽略的个人文件、私有原图；排除可重装node_modules和.git内部文件，Git历史另保存在bundle。备份及克隆历史含早期原图，必须按私有资料保管。旧ZIP个人修改不会自动覆盖标准Git版本，原文件及备份均保留供核对。

Fetch失败时工作文件尚未改变；有实际更新时在应用任何代码前备份并验证。迁移在网络下载前先备份，网络或校验失败原ZIP不动。中途文件锁等异常不强行清理当前工作区；保留备份及04恢复入口。
