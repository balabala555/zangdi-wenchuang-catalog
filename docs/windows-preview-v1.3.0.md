# Windows 固定目录测试指南（V1.3.0）

本指南只运行本地测试网站，不提交、不推送、不合并、不发布。首次配置后，不必反复下载和解压 ZIP。软件 V1.3.0，品牌 VI 仍为 V1.1。

## 首次配置（按顺序，每完成一步再继续）

1. 你的 Node.js 已安装，不必重复安装。若电脑没有 Git，从免费官方入口 https://git-scm.com/downloads/win 安装 Git for Windows，保留默认选项；安装后重新打开文件夹。
2. 下载一次 [V1.3.0测试分支ZIP](https://github.com/balabala555/zangdi-wenchuang-catalog/archive/refs/heads/test/vi-v1.3.0.zip)，解压，进入能看到 `01-setup.cmd` 的文件夹。
3. 双击 `01-setup.cmd`。工具仅克隆指定测试分支到 `%USERPROFILE%\zangdi-preview`，通常为 `C:\Users\ytb\zangdi-preview`。需要网络；目标目录非空会停止，不覆盖。遇到错误保留窗口内容，不自行删除原图或项目。
4. 打开上述固定目录，双击 `02-start.cmd`，保留黑色窗口。
5. 点击或复制打开 http://localhost:3000 ，检查页脚软件版本 `v1.3.0`。首页默认商场店照片待补提示属于本候选已知素材缺口，可点击“八廓街店”查看真实门头。

只有图片再处理开发才需要 npm 及 sharp 构建工具；日常本地预览直接启动 Node，不执行 npm install，不触发 sharp 安装或水印重做。

## 后续更新（不再下载 ZIP）

1. 到正在运行的黑色窗口，按 `Ctrl+C` 关闭预览。
2. 在固定目录双击 `03-update.cmd`。它检查目录、仓库、分支和本地修改，只获取 `test/vi-v1.3.0` 并快进；有分叉、本地修改或服务器未关闭会停止。每次实际更新前保留备份分支及恢复记录。
3. 成功后双击 `02-start.cmd`，刷新浏览器。窗口会显示版本；更新窗口也显示提交编号。浏览器清单保存在各自设备浏览器中，不会自动跨设备同步。

如果显示“已是最新版本”或 updated:false，无需再次下载。不要在固定目录手工放个人文件；有本地修改时，工具拒绝覆盖，先保留文件并请协助检查。

## 恢复上一版

关闭服务器后双击 `04-recover.cmd`，工具在独立 `recovery/preview-…` 分支打开本工具上次更新前的版本，保留新测试分支，不删除文件、不强制重置。首次克隆尚未更新时没有恢复点，会明确停止。

需要回到较新测试版时，先关闭服务器，再双击 `05-return-test.cmd`，随后双击 `02-start.cmd`。这些操作都要求工作区干净。

## 手机访问

电脑保持预览窗口开启，手机和电脑连接同一可信 Wi-Fi。打开启动窗口列出的 `http://192.168.…:3000` 等局域网地址；手机不能用 localhost 访问电脑。若 Windows 防火墙询问，仅允许可信的专用网络，无需管理员运行网站、关闭防火墙或开放公网端口。公司网络隔离可能阻止访问。

普通局域网 HTTP 上手机原生文件分享可能不可用，保留导出图片预览及长按保存，再发微信客服。原生分享取决于浏览器、安全上下文和用户点击；不能因没有分享按钮判定商品清单损坏。

## 清理旧下载目录

确认固定目录已运行并核对商品资料后，旧 ZIP 和重复解压目录可由你自行决定清理。先另行保存自己的原始照片、设计素材及未提交修改；工具不会自动清理任何旧文件夹。Git 历史中有早期原图，完整克隆目录和备份也应按私有资料保管。

## 验收顺序

双店切换（商场店缺图提示）、七类及搜索、三色蘑菇包照片、不同款式及数量、清单金额与删除、生成图片、两个客服号与二维码、长按保存与系统分享。两位客服平等服务两家店，网站网址继续隐藏。真实 Windows、苹果、安卓、微信浏览器操作仍须你集中验收；云端 Chromium 模拟不能代替真机。
