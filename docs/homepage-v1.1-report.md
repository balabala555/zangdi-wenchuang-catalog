# 首页视觉 V1.1 开发与验收报告

软件版本：1.2.0；品牌 VI / 确认首页设计：V1.1。沿用测试分支与1.1.1成果，不回退，不发布正式网站。

## 素材及真实资料

使用 homepage_V1.1_assets.zip 中的01门店主图、02门头、03软萌小羊/小物、04羊毛毡、05尼泊尔与藏地手作、06传统手工制品、07旅行纪念及其右侧手串裁图、08织物、09彩虹小羊。10补充实拍暂仅私有保留，未擅自用于某个具体款式；11 Logo与既有确认VI同款，网页继续使用已校验、质量更好的确认PNG，不重新描绘。效果图仅用于排版参考，不作为商品照片或售价推断来源。

上传使用说明明确确认软萌小羊20元/个、彩虹小羊25元/个，因此只增加这两件真实商品。每张图包含多件实物，未把不同图案虚构成已确认款式；款式、材质、尺寸、库存明确待客服确认。蘑菇包三款资料和映射保持，六件历史演示商品仍保留并标注演示。

## 本轮修改

- 首页按确认稿布局：暖米白/木棕/品牌深绿，真实LOGO、顶部搜索、门店主视觉、七类入口、门头入口、两件人气小羊及手机底部导航。
- 七类为：随手带走的小物、羊毛毡生活好物、尼泊尔与藏地手作、尼泊尔传统手工制品、藏地旅行纪念、手串与饰品、织物与穿戴。旧分类通过别名匹配仍可查，未修改历史商品资料；未录入的分类显示诚实空状态。
- 新增 src/homepage.js 维护图片用途、七类及隐私遮挡/裁剪策略；新脚本 optimize-homepage.mjs 与现有图片生成同在 images/启动/构建流程自动运行。
- 原图只放 .private-originals；设计稿、Logo参考和说明在 .private-designs，不提交。公开门店图先对收款码与Wi-Fi区域做不透明实色遮挡，再压缩/水印。此处实色遮挡是使用说明要求，非图片缺损或场景重绘。
- 首页照片输出240/640/1600尺寸WebP及带保护的JPG兼容文件；采用确认品牌素材和交替客服号永久合成。首页场景采用品牌标识＋分布式保护，商品图片继续完整三层保护及确认落款。无AI生成、调色或改动商品造型；07仅按授权从右侧裁剪。
- 保留款式相册、数量、旧清单、金额、复制、PNG、原生分享优先及长按备用。底部快捷导航连接原有功能，门店照片弹窗不伪造营业时间或具体门牌。
- 首页派生图加入内容摘要缓存、懒加载和离线预览；原图不得作为失败回退。图片/配置摘要不变时复用，配置有变时从私有原图处理，禁止叠加旧图。

## 自动化与性能

- npm run check：40项自动化测试、版本保护与构建通过。新增真实价格/待确认信息、七类映射、多尺寸水印、原图摘要、实色隐私面板及无私有原图时防叠加复用检查。
- 浏览器回归：真实商品、首页分类搜索、软萌/彩虹小羊合计45元及PNG、门头与客服入口、蘑菇包三款、旧清单、金额复制、分享模拟/取消/下载/长按备用、网页与离线二维码、千条仅测试数据分页均通过。
- 手机390×844（DPR 3模拟）、电脑1440×1000（DPR 1）实际Chromium截图保存在 docs/screenshots；另检查窄屏横向溢出。截图为运行页面，不是设计效果图。
- 本地主图手机约85,924字节（约86KB），电脑384,170字节（约384KB）。9个首页展示来源（含07同源裁剪）输入合计7,296,234字节，240图合计146,340、640图789,346、1600图3,271,380字节（约3.27MB），细节见实际生成清单。这些统计对应当前生成结果。
- 仅主图高优先加载，手机主图明确限制为640档，避免高DPR额外请求1600档；商品相册详情仍可加载完整细节图。分类和人气图懒加载。没有新增第三方请求或npm依赖。上千款测试验证分页与有限预加载，不代表已经做真实千款独立图片压力测试。
- 性能JSON是本地Chromium冷导航记录，不是移动网络、苹果Safari或微信真机速度承诺。单文件离线网页为携带照片和品牌素材会更大，仍维持16MiB照片内嵌预算；大目录请用完整HTTP网站。

## 风险、费用及验收

- 新增费用：无；未引入收费API、插件、云服务、登录或分享限制。
- 请人工复核首页构图、七类裁图、收款码/Wi-Fi遮挡范围；小羊图为群体展示，款式/规格待客服确认，并非可指定图案库存承诺。
- 苹果/安卓/微信原生分享、长按保存、相册权限仍需真机验收。
- 旧Git历史中的早期原图仍存在，未擅自改写；新的高清原图和设计源均未加入公开文件。
- 仅测试分支；等待人工验收，不合并main，不发布网站。

## 本地预览

下载新的测试分支ZIP并解压到新目录。可打开 dist/index.html 离线查看；需要HTTP预览时运行 npm ci --include=optional，再 npm run dev，按终端显示地址打开。检查页脚“v1.2.0 · VI 1.1”以确认版本。分类/门头/人气卡均可点击；选择商品后测试清单及图片分享保存。
