# V1.6.0 受保护线上发布：本地验收版

本轮只实现和本地验证。未配置真实Cloudflare账号、未上传三款商品、未执行公网部署，main未改。现有网址和商品库不动。

## 经营定位与服务

实体店官方线上选购渠道；微信客服人工确认库存、运费及付款。不增加支付、注册或收货地址。本地后台只监听127.0.0.1；最终正式顾客网站无登录限制，但本阶段仅允许受保护测试。

使用已有Cloudflare Pages项目 `zangdi-wenchuang-catalog` 和其现有生产分支；不创建新项目，不要求GitHub main。不使用R2、数据库、Access或付费服务器。

无绑卡保护使用Pages高级模式 `_worker.js`（免费Functions）：服务端验证随机256位测试口令，全部页面、JSON、图片和二维码走同一验证。不是前端密码页面。每个素材用AES-256-GCM加密；解密密钥由高强度凭据派生，云端不存明文口令或解密密钥。上传目录仅包含加密二进制、服务端验证程序、全路径路由和无商品内容的中性页面。口令必须由本机随机生成，禁止弱口令。

即使免费Functions额度耗尽并fail-open回退静态文件，也只会拿到密文或中性页面，不会得到商品清单、照片或二维码。建议在Cloudflare设置Runtime → Fail closed，额度耗尽停止服务；此设置需人工核对，不自动更改。

**费用边界：**免费Functions通常共用Workers Free的100,000请求/日，所有测试素材均需要验证，不能套用纯静态无限请求承诺。项目仍受20,000文件/单文件25MiB等限制。本程序不调用订阅、升级、绑卡或收费资源创建接口；不保证平台未来不改政策。若免费账号实际无法运行Functions或要求支付方式，停止云端接入，继续本地验收，不能取消保护绕过。

官方来源：
- https://developers.cloudflare.com/pages/functions/advanced-mode/
- https://developers.cloudflare.com/pages/functions/routing/#fail-open--closed
- https://developers.cloudflare.com/pages/functions/pricing/
- https://developers.cloudflare.com/pages/get-started/direct-upload/
- https://developers.cloudflare.com/pages/platform/limits/

本轮读取了Cloudflare官方cloudflare-docs仓库对应production文档。没有通过用户账号核验免费资格，真实平台行为待批准后测试。

## Windows本地验收（未部署）

沿用07-admin.cmd，无新增启动脚本。安装固定Wrangler4.166.0；公开发布工具要求Node22.12或更新，用户已有Node26可用。07会检查组件并准备免费依赖，不初始化或迁移商品库。

1. 核对原三款资料、照片、价格、款式和本机已发布版本；必要时先保存草稿，再用列表“发布/更新已发布商品”确认进入本机已发布版。全局线上发布不偷偷包括未发布草稿。
2. 点击“生成线上发布预览（不联网）”。不需要Cloudflare令牌即可离线验收。
3. 点击“打开本机发布预览”，再点显示的链接。在原顾客页面核对三款真实商品、15款照片、价格、库存及PNG。
4. 原“用已保存3款真实商品验收”按钮也会在私有副本生成加密发布包；所有变价、库存测试只在副本执行，结束清理，不上传。

本地预览是127.0.0.1临时端口，不提供公网访问，只有本机用户可达。服务器端测试口令的全路径验证通过Wrangler本地运行环境自动测试；普通本机预览用于快速核对商品。

**当前不要点击联网发布。** 用户已确认Git生产自动部署及预览自动部署均关闭，并授权提交推送测试代码。代码交付至test/admin-v1.4.1-soft-watermark，同时同步既有test/vi-v1.3.0兼容更新通道；推送成功后可由03取得，main不改。更新前保存编辑并关闭旧07窗口，双击03-update.cmd，再双击07-admin.cmd确认V1.6.0。

## 获得批准后的首次配置（每次只指导一个动作）

1. 店铺控制Cloudflare账号，核对免费计划；不要购买或绑卡。开启账号安全验证。
2. 核对现有Pages项目；关闭Git生产和预览自动部署。本程序检查两项；只关闭生产、预览未关闭时会停止，避免Git重建覆盖或产生公开旧页面。
3. 创建仅具所需Pages编辑权限的API Token，限定店铺账号；不要使用Global API Key。账号级Pages权限可能覆盖该账号其他项目，令牌只交授权店员管理，支持撤销和轮换。令牌不要发送到聊天。
4. 在本机“配置发布账号”输入账号ID和令牌；Windows使用DPAPI CurrentUser加密，绑定当前Windows用户。其他系统开发验收使用私有文件权限；无承诺抵御Windows账号被攻破。
5. 在后台查看随机测试访问口令。测试用户名shop-test；浏览器HTTP认证框输入口令。不是Cloudflare密码，不向普通顾客分发。
6. 明确批准后才输入“确认上传到受保护测试网站”发起部署。按钮调用固定版本Wrangler，不要求用户敲命令。生产部署只是更新Pages固定地址，不涉及GitHub main合并。

先前已经公开的演示部署及其历史链接不会被本轮本地代码自动保护。新包所有内容加密、所有新部署入口均由Worker验证，但旧的公开部署需要另行核查；不要误称已经保护了当前网址。

## 发布、库存与失败保护

- 读取已冻结的publication.products，导出公开字段白名单，排除demo、回收站、商品售罄/下架；款式售罄/库存0保留说明但不可选，款式下架隐藏。
- 独立catalog.json，不把Windows真实商品硬编码进源码或提交Git。名称、分类、价格、介绍、照片、款式、库存、排序及状态沿用原适配器。
- 只复制已验证水印衍生图、固定品牌素材/真实二维码/门店保护图；原始文件不复制，旧角落水印或缺客服的图片拒绝发布，提示先从私有原图升级。
- 先校验发布包和当前版本，再校验远程项目/网址；不执行创建项目命令、不创建收费资源。发布前本机完整ZIP备份。
- Wrangler从独立上传目录运行，命令行没有令牌；令牌仅传给子进程环境，工具日志留在私有目录，不返回给网页或上传。
- Pages完成部署后验证固定网址、部署专属网址，以及HTML/JSON/图片的未授权401和授权商品版本；成功才标为线上成功。重复点击被阻止，版本变化需要重新准备，图片以指纹关联不重复创建商品。
- 上传失败不会主动删除上一版。上传完成后验证失败，若当前部署仍属于本次发布，尝试回滚到记录的上一版，并核对结果；并发或网络异常无法确认时明确标记待核对，不伪称原网站未变。保留手动回滚入口和私有发布记录，重启可读。
- 如果回滚目标原本是公开演示站，回滚会恢复原来的公开演示状态，不会额外公开本次商品密文的口令。
- JSON/页面不使用陈旧缓存；图片按内容指纹，测试版访问要求验证。顾客加入清单和导出前复核发布版本、库存，加入清单不扣减库存。
- 本地草稿/原图/历史/备份不修改，公布并非上传私人商品库。凭证和线上包不进入完整商品ZIP；迁移电脑后需重新配置发布凭证。

每日只需本地后台。当前本机“更新已发布商品”与“发布到线上”明确分开，以免保存草稿意外公开。未来正式开放须单独批准，不能通过移除Worker绕过当前测试保护。

- 开发环境没有用户Windows的三款真实照片，自动夹具不能替代真实商品验收。提供本地真实资料副本入口，不要求重录或上传原图。
- Windows DPAPI、银联卡条件下Cloudflare账号免费Functions资格、真实令牌权限及Wrangler实际部署、回滚尚未执行。
- 国内微信、iPhone HTTP认证框、图片加载/原生分享及拉萨三网可达性需真机测试。若微信不支持HTTP认证，测试人员改用系统浏览器，不能公开保护资源绕过。
- 测试口令为共享口令，不是员工身份系统；授权店员能保存并分享已解密图片，不能承诺阻止分享。授权交接必须转交店铺本地资料和账号，不绑定开发者账号。
- 加密与服务端验证增加测试阶段开销；本机运行通过不等同于Cloudflare免费CPU额度或国内加载性能已验收。免费额度不足时停止测试，不自动付费。
- Pages历史版本会按平台保留规则清理，本地完整备份仍必要。撤回不等于收回别人已保存的图片。
