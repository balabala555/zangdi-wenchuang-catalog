# V1.4.0「本地商品管理基础版」第一阶段报告

日期：2026-11-21。基于V1.3.3 `6edf0977ec1a8f11758daae61c9ee418f93423b5`，在独立分支`test/admin-v1.4.0-phase1`开发。品牌VI保持1.1。本轮仅本地开发，不推送GitHub、不合并main、不连接外部服务或部署；提交编号见本次聊天交付。

## 已完成

- 简体中文浏览器管理台：新增、编辑、名称/分类/款式搜索、状态筛选、设置价格/单位/尺寸/材质/介绍及在售/售罄/下架。
- 颜色款式增改，固定编号；改名保留历史别名，移除款式归档，照片引用不随名称错误转移。没有商品或照片永久删除操作。
- 首次将已有9条资料复制到私有商品库，3件真实商品和6条原演示资料全部保留；真实商品优先展示，演示明确标注。新商品默认下架，使用原七大分类，旧分类不擅自改写。
- 本地单品预览：显示保存后的资料、状态、款式与原有已嵌入水印照片；缺图明确占位。原有照片按校验和验证再展示，不能用任意文件路径读取私有原图。
- 默认私有数据位于Windows LOCALAPPDATA的ZangdiCatalog/merchant-data，禁止放在代码目录或其祖先目录内。以后启动只读取已有资料，不重新覆盖导入。
- 完整不可变资料快照、SHA-256校验、临时文件写入并fsync后原子切换CURRENT、写入锁与版本冲突校验。两个窗口编辑，后保存者不能覆盖先保存结果。
- 自动保留保存前后版本、手动备份、下载资料备份、从历史版本/文件明确确认恢复。恢复建立新版本，旧版本不删除；CURRENT损坏不会自动重置，有效快照仍可从界面恢复。中断切换时旧CURRENT保留，新快照也可找回。
- 独立服务默认127.0.0.1:3100，新增07-admin.cmd，不需Sharp或新依赖。随机启动授权只在当前进程有效，URL片段加载后清除，Cookie HttpOnly/SameSiteStrict，写入要求CSRF及匹配Origin；校验Host、防跨站、禁止嵌框。没有写死密码、公开密钥或持久化授权令牌。
- 顾客服务器仍只服务原页面与public/src，管理文件和API没有加入顾客端路由。保存只变本地资料，源代码中的真实商品与顾客清单不变。

## 数据与安全边界

资料快照在同一私有数据目录，可防误修改，不能替代另一块磁盘的备份；下载文件只有资料和照片引用，不包含原图或图片二进制。阶段一没有图片修改，原照片与既有原图备份继续保留。照片统一私有存储及打包备份属于下一阶段。

基础版依赖本地支持硬链接的文件系统及可信Windows账户，限制单机使用，不宣称多租户/企业权限隔离。目录写入或校验异常停止而不强制覆盖。资料上限8MB、导入上限10MB；快照不自动删除，会累计占空间。私有库和下载备份不要放公开仓库。

下一阶段建议先验收本轮新增/编辑/恢复，再接入真实照片上传、款式配图、私有原图管理和自动水印；最后衔接顾客端预览及明确发布确认。未经确认不推送外部服务，不覆盖实际数据、不合并main、不上线。
