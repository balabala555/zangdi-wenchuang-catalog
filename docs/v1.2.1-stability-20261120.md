# V1.2.1 细节优化与稳定性报告

日期：2026-11-20。软件版本保持1.2.1，构建标识20261120-stability；品牌VI保持1.1。基于ea0ed5e继续，继承用户已在Windows和苹果Safari验证过的V1.2.0功能及现有主图精修成果，不回退，不增加业务功能。

## 修改内容

- 主图水平/透视、暖色微调、不可逆柔化隐私遮挡和电脑/手机裁剪已经在上一提交完成，本轮逐字节保留，不重复编码。详情和原对比见 [主图报告](hero-refinement/report.md)。
- 首页LOGO复用静态图片节点，不再启动时删掉重建；优先加载、固定宽高比例，深浅素材切换先解码，失败时保留可读品牌名。这是降低闪烁/重排风险，未声称在真实Safari复现或完全消除所有网络延迟。
- 七类图片提前声明尺寸，保留原生懒加载、受保护JPG回退。网络失败后仍保留分类入口和占位高度，避免整块空白或文字重叠；网络恢复最多重试一次，待重试队列最多12张，不对上千商品批量重载。
- viewport-fit=cover配合上下左右安全区；页面按固定导航实际边框盒高度预留底部空间，包含安全区padding。ResizeObserver观察边框盒，老实现回退普通观察；可视视口变化时同步弹窗最大高度，普通页面操作提示移到导航上方。无视觉设计变更。
- 新增只读 `npm run doctor:images`，输出Node、平台、架构、原生/官方WASM后端及WebP实际编码解码结果。扩展原生模块不可用时的WASM测试，覆盖主图隐私、透视、色调和压缩操作。
- 未修改商品、价格、品牌素材、图片二进制文件、缓存、永久水印或分享规则；未增加依赖、账户、付费API及服务。

## 无法自动验证，须真机验收

1. 当前环境无法安装WebKit：官方Playwright下载地址被环境域名策略以403阻止。因此本轮没有真正运行Safari内核；iPhone Safari及Android微信UA测试只是Chromium视口/UA模拟，不能等同实际浏览器内核。
2. iPhone Safari首次加载LOGO、快速上下滚动及工具栏展开/收起、刘海/横屏/手势安全区、键盘弹出关闭，仍需实机检查。
3. Android系统浏览器和微信内置浏览器的工具栏、系统分享面板、长按保存、相册权限及微信目标选择，无法由模拟测试保证。
4. Windows真实npm安装、DLL/系统运行库和具体CPU架构不能在Linux完全验证。原生禁用后的WASM模拟验证只证明回退路径，不是Windows安装成功的证明。用户原先Windows正常环境不需为了本次更新重新安装Node。
5. 主图构图和柔化遮挡的自然度仍待人工验收；旧Git历史中的早期无水印原图未擅自清理。

## Windows检查及预览

下载最新测试分支ZIP，解压到新目录，保留现用正常版本。若无需HTTP服务，可先打开dist/index.html。

需要本地运行时，在项目目录执行 `npm ci --include=optional`，再 `npm run dev`。有图片模块报错时运行 `npm run doctor:images` 并保留完整输出。不要复制其他系统的node_modules，不要删锁文件或执行强制升级；已正常运行的Node无需更换。新装优先使用正确架构的Node LTS；若路径过长，可解压到较短目录如C:\zangdi-test后再安装。

软件版本为1.2.1，区别于前一主图构建的修订标记为20261120-stability，保存在src/version.js和页面html的data-revision；下载入口和Git提交用于确认最新包。

本轮仅测试分支，无新增收费服务，不合并main、不发布正式网站。等待真机验收后再进入下一阶段。
