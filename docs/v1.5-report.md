# V1.5.0 本地发布与库存阶段报告

基线f2df4a5；沿用当前test/admin-v1.4.1-soft-watermark及03固定测试更新通道test/vi-v1.3.0；main不改。

## 完成

- 复用原后台、顾客页面、相册、款式价格、清单/PNG、轻水印、03/02/07。
- 显式完整备份并初始化本地已发布版本；保存草稿与顾客版本隔离，单件发布/更新/撤回及状态查看，不修改原图。
- 每款独立手工库存、0售罄、可选数量上限、旧页面发布版本/库存检查、加入清单不扣库存。
- 发布快照与草稿共用原有校验封装/原子CURRENT；失败不切换已发布版，历史版本保留。发布版本有独立唯一标识，恢复后再发布不会误复用旧价页面。
- 库存和发布为schemaVersion 1兼容可选字段；ZIP/JSON/历史恢复支持，新备份可整体恢复，旧备份恢复草稿时保留当前发布版及可管理记录。
- 新增基于用户真实三件商品的私有副本验收入口，运行后清理副本，不在真实库改价格/库存或进行发布。

## 未完成及待确认

- **未实现或开通线上托管/固定公网网址同步。** 本轮“发布”仅在本机测试，已在界面/确认框注明。云存储、账号和密钥均未配置。
- 推荐进一步评估Cloudflare Pages静态JSON/水印图Direct Upload，不先上数据库；常见免费额度和潜在限制、注册/令牌及发布保护流程见[线上方案](v1.5-online-proposal.md)，等待用户确认后实施。官网额度核对受网络403限制，不能保证2026最新账号政策。
- **用户Windows中的真实三款实拍尚未在开发环境取得，不能声称已完成实物验收。** 已提供真实资料隔离验收按钮和具体浏览器步骤，不要求重新录入或上传原图；需要用户本机运行并核对报告/照片/PNG。
- 手工库存不是订单预留，多客户并发不承诺防超卖；清单不是支付订单，客服成交后维护库存。
