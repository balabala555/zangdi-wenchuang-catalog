## 本次完成

- 照片移除二次确认；取消后不修改关联。照片库仍可查看全部成功上传的照片，不自动删除原图和未引用文件。
- 款式独立价格与三状态；留空继承商品设置，旧资料无需补填，改名/归档保留编号及价格/状态。多款式缺图严格占位，预览售价及状态随款式切换。
- 同分类/同置顶组上下移动，设置/取消置顶；顺序存于商品数组，置顶字段兼容扩展，不触碰顾客数据。
- 确认移入回收站、正常列表隐藏、恢复商品，商品/价格/款式/照片和历史版本保留；没有永久删除接口。
- 发布前检查只读，区分可以发布/需要完善/存在错误，检查名称、分类、价格、照片关联、可用状态、文件完整性、品牌保护和客服配置。正式发布按钮和接口仍关闭。
- 新照片分布式半透明品牌及两个客服微信交替，真实原图经本地字体路径渲染/合成；字号随图片缩放，透明度/角度/颜色读取现有品牌配置，轻微反差描边。没有AI，不裁改实物，不修改公开既有VI图片。
- 旧角落图兼容读取且检查提示；确认升级时先生成完整ZIP，再从原图生成新的独立照片资产，最后切换当前引用；失败不提交，原始文件、旧展示图和历史引用均保留。
- 数据schemaVersion 1保持，可选字段扩展；启动只读不自动改库。首次写入先保留完整资料基线、原CURRENT指针，当前指针损坏仍可恢复。旧快照/ZIP在新版恢复，保留新增款式/置顶/回收站字段。

## 尚未开放及真实风险

- 正式发布、顾客端资料同步、多人协同、精确库存/成交管理仍未开放，属于原定边界。管理在售状态不等于对外展示。
- 未发现测试范围内的数据丢失或图片损坏。现有Windows商品库不清空、不覆盖；测试只在临时目录进行，并不能代替用户电脑上的原库验收。
- 旧角落图需要明确确认才升级；无私有原图或文件损坏不会强行处理。现有缺失旧原图会继续在备份界面提示，无法从保护图还原原图。
- 新版能读旧资料与备份，不代表旧程序能理解新版分布式登记/回收站；退版需先备份并恢复旧资料基线，不能直接混用两个版本。无永久删除，文件会累积占用磁盘。
- Windows真实CMD/NTFS/杀毒软件、首次安装网络、默认浏览器、保存对话框以及苹果/安卓/微信原生分享需真机验收；模拟测试不等于真机测试。
- 没有新增依赖、费用、外部服务或账号要求；仅使用已有本地开源图片/ZIP组件。
