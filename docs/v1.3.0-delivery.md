## 开发前核查与复用

项目为原生 JavaScript ES Modules、CSS、Node 静态服务及 Canvas PNG 导出，无需重建框架。已有商品相册、款式图片、搜索分类、数量/合并/金额/删除、localStorage旧清单校验、文字复制、分享/长按保存、离线页面和图片保护机制均保留。

商品资料在 `src/data.js`，既有压缩/多尺寸/缓存及水印配方在图片生成脚本和生成清单中，原图私有输入。品牌真实素材及两位客服资料在 `src/brand.js` 和 `public/branding`。已有七类首页实拍、八廓街门头与精修内景可复用；未找到可确认的八廓商场店实拍，不能用其他图片冒充。

清单原本以商品ID＋款式分别记录数量，支持多次加入；本轮增加“加入并继续选款”，避免关窗再开，未引入新的清单结构、支付或库存系统。

## 尚未完成与风险

1. **缺少八廓商场店真实照片**。私有建议路径 `.private-originals/stores/barkhor-mall.jpg`；未来经现有隐私遮挡、压缩、多尺寸和永久水印流程生成 `public/images/stores/barkhor-mall.jpg` 后接入，禁止直接公开高清原图。目前首页明确占位，双店实景这一验收项未完成。
2. 真机待验：Windows双击脚本/防火墙、苹果Safari、安卓及微信系统分享/保存、工具栏安全区和实际触摸手势。Chromium UA/尺寸与事件模拟不是Safari/WebKit真机；环境下载WebKit遭官方域名访问策略403阻止，未把未运行测试记为通过。
3. 普通局域网HTTP下原生分享可能受安全上下文限制，图片预览及长按保存继续可用。用户取消分享不自动下载；分享行为取决于浏览器。
4. 历史提交曾包含无水印原图，新增忽略规则不能清除已公开历史。本轮没有改写历史或删除历史文件；清理历史、缓存需单独授权和协调。当前不新增公开原图或设计源。
5. 不开发支付、库存同步、会员、大型后台或多商家系统。系列多款数量以原格式连续选择解决，无高风险结构改造。
