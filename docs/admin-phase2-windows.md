# V1.4.0 第二阶段：Windows 下载、启动与验收

这是独立的本地管理测试版，不是正式网站。第一阶段已验收资料继续使用，不需要重新录入。

## 下载和启动

1. 关闭第一阶段07的黑色服务窗口（Ctrl+C），保留原项目文件夹。不要同时启动两个管理版本。
2. 打开 [第二阶段分支](https://github.com/balabala555/zangdi-wenchuang-catalog/tree/test/admin-v1.4.0-phase2)，点击绿色 **Code → Download ZIP**。也可用[直接下载ZIP](https://github.com/balabala555/zangdi-wenchuang-catalog/archive/refs/heads/test/admin-v1.4.0-phase2.zip)。
3. 将ZIP全部解压到一个新的文件夹，不覆盖旧版文件夹；打开包含`package.json`的项目根目录。
4. 双击 **07-admin.cmd**。首次启动会自动安装免费开源的图片和ZIP组件，请联网并等待；以后正常启动不重复安装。不需要购买数据库或服务器，不用每天输入命令。
5. 浏览器自动打开；没有自动打开时，使用黑色窗口显示的完整本机授权网址。页面右上角应为 **V1.4.0 · 第二阶段**。不要分享后台授权网址。
6. 核对原来录入的商品仍在，再开始编辑。点击 **备份与恢复 → 生成并保存完整ZIP**，选择移动硬盘等私有位置保留第一份完整备份。

原稳定03仍针对V1.3.3通道，不能用它将旧版切换到本管理分支；本轮使用新目录07。不要覆盖稳定目录、手动切换main或强制Git更新。升级后的本地资料仍在同一个仓库外目录：

`%LOCALAPPDATA%\ZangdiCatalog\merchant-data`

首次写入前自动保留`phase2-upgrade/catalog-before.json`和原指针；不清空或重新导入已有商品库。安装依赖不修改商品资料。

## 最少操作录入商品

1. 点击 **新增商品 → 选择照片（可多选）**。
2. 等待上传/水印完成，填写 **商品名称、价格**，检查分类（记住上次类别）。点击 **保存到本地**。
3. 需要时再展开尺寸/材质/介绍、颜色/款式。编号自动生成，不要求库存数；单位默认“个”，状态默认“在售”，仅为本地状态。

照片支持JPG、PNG、WebP，单张25MB以内、最多4000万像素、不支持动画；每批20张、每件50张。iPhone的HEIC请先在电脑导出JPEG原实拍兼容文件，本版不接收HEIC。超限或格式错误会明确提示，不会改写已有商品。

新上传照片只永久加入右下角小巧“扎西德勒鸭”，没有满屏或第二层水印。原始文件保留上传时的原字节，不裁剪、不覆盖。不能自动识别任意外部水印，请选实拍原图；已登记的本系统展示图会拒绝再次作为原图上传，相同原图自动复用。

## 建议验收顺序

- 新建一条“第二阶段测试商品”，上传1张，再补2张。检查进度、缩略图、清晰的右下角文字；点击上移/下移、设为封面，保存后点“预览”。
- 需要款式时展开“颜色／款式”，给照片选择对应款式；在本地预览切换款式核对。公共照片供通用展示。
- 移除一张照片并保存；点击“已上传照片”仍应找到它。移除只解除展示关联，不删除原图。取消编辑后的成功上传照片也留在照片库。
- 修改价格并保存；直接在列表状态框设置售罄、在售、下架，不用打开编辑页。检查照片和其他资料仍在；失败应提示原因，不假装保存成功。
- 关闭服务窗口，重新双击07，核对资料和照片保持。
- 点击“备份与恢复 → 生成并保存完整ZIP”。Chrome/Edge支持保存位置选择时会先询问位置；不支持的浏览器使用正常下载流程，可在浏览器开启“下载前询问每个文件的保存位置”。生成后的ZIP也可在“已生成的完整ZIP”重新下载。
- 再改一项测试商品资料，选择“恢复完整ZIP”，等待校验，核对恢复整个商品库的提示，勾选确认后恢复。恢复到备份时的资料；操作后的版本仍保留。恢复不是合并商品。
- 可用不完整或损坏的测试ZIP检查明确失败提示，原商品库应保持不变。不要故意损坏实际资料目录。
- 打开原顾客网站核对商品、搜索、清单和图片保存保持原样。本后台尚未发布新增商品到顾客网站，是本阶段的预期行为。

## 备份边界和回退

完整ZIP包含当前/历史商品资料、分类、款式、状态、所有已登记照片的原图/水印展示图及关联，包括暂未使用的照片。ZIP校验路径、格式、长度和SHA-256后才允许确认恢复；恢复前保全当前资料和被替换文件，安装照片成功后最后切换资料指针。并发编辑会阻止覆盖。

旧商品若在本机没有私有原图，界面和ZIP清单会明确记录缺失；现有受保护展示图仍纳入。不能从带水印图恢复真实原图；需要把你保留的真实原文件通过上传入口补入。旧照片不会被本轮重新加水印或改变内容。

JSON备份仍兼容，但只包含资料及照片引用；迁移到其他电脑必须使用完整ZIP。保存在同一台电脑上的备份不能防整机/硬盘损坏，建议定期复制到移动硬盘，妥善保管，勿上传公开仓库。

没有自动清理原图或历史版本，照片越多磁盘占用越大；未来清理需要独立审核。生成ZIP需要额外空间。基础版ZIP上传限8GB、解压总计24GB、最多5万文件；超过时明确停止，不清空资料。备份不加密，按私有文件保管。

第一阶段旧程序不理解新的`asset:`照片引用。需要回退时，先下载完整ZIP保存第二阶段成果，再由维护人员协助用“进入第二阶段前的资料基线”恢复原资料后使用旧程序；不要直接用旧程序强行编辑第二阶段商品库。程序恢复与商品资料恢复是两件事。

## 本阶段未开放

顾客端同步/正式发布、多人协同、精确库存、云服务均未开放。未来顾客端在售展示、售罄/下架隐藏的发布规则已保留本地状态，未自动同步。

真正Windows双击、安装网络/权限、浏览器保存对话框仍需按以上步骤真机验收；Linux自动化模拟不能替代Windows验收。
