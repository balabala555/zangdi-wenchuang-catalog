## Windows验收操作

下载新的测试项目并解压到新文件夹，保留旧版本作为对照。打开 dist/index.html 可直接离线查看。需要HTTP预览时在项目目录运行 npm ci --include=optional，然后 npm run dev，访问 http://localhost:3000。已安装的 Node.js 无需重新安装。

检查首页彩色LOGO、三款照片和分布式品牌章，逐款加入清单后生成图片；检查底部上传的新落款和两个微信号，扫码确认。苹果/安卓/微信的原生分享和相册权限仍需真机验收；浏览器模拟通过不等于真机已验收。
