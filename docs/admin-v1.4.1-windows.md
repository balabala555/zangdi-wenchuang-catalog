# V1.4.1：Windows 下载、启动及验收

本轮独立测试分支：`test/admin-v1.4.1`。基于已通过验收的V1.4.0第二阶段上传修复1，不替换正式网站。

## 下载并启动

1. 在旧07黑色窗口按Ctrl+C，停止旧后台；保留旧项目目录。网页只关闭不等于停止服务。
2. 打开[测试分支](https://github.com/balabala555/zangdi-wenchuang-catalog/tree/test/admin-v1.4.1)，点击 **Code → Download ZIP**；也可[直接下载](https://github.com/balabala555/zangdi-wenchuang-catalog/archive/refs/heads/test/admin-v1.4.1.zip)。
3. 完整解压到一个**新的文件夹**，不覆盖旧项目。打开包含package.json的目录，双击 **07-admin.cmd**。首次需要联网自动准备免费组件，继续沿用已安装的Node.js。
4. 右上角应显示 **V1.4.1 · 商品管理完善版**。核对原有10件资料及照片仍在，然后先到“备份与恢复”生成完整ZIP，另存移动硬盘等私有位置。

商品库仍是`%LOCALAPPDATA%\ZangdiCatalog\merchant-data`。启动不重置、不迁移字段、不覆盖既有商品。无需重新初始化、手动改资料文件或输入命令。原03仍是旧稳定顾客端更新通道，不能用它切换到本管理分支。

## 日常操作

- **新增商品**：添加照片 → 商品名称、价格 → 保存到本地。编号自动生成，分类记住上次选择，尺寸/材质/介绍仍选填。
- **照片**：添加多张，可上移/下移、设为封面；“已上传照片”可找回未使用的图。移除要再次确认，只解除当前商品展示关联，原图和历史照片保留；保存后生效。
- **颜色／款式**：需要时展开，点击“添加款式”，填写名称，可另设售价、在售/售罄/下架。售价留空、状态选“沿用商品状态”，就使用商品设置。修改商品价格后，未独立定价的款式随之变化，已独立定价的款式保持自己的价格。
- **款式配图**：在每张照片下方选择对应款式；公共照片用于商品总体展示。多款式预览只展示该款式明确关联的照片；缺独立图会提示，不借用另一颜色图片。单款商品仍可直接使用封面/公共照片。
- **排序**：在列表选分类，使用上移/下移；同分类内分置顶组、普通组排序，置顶组优先。设置置顶或取消置顶也只影响本机。筛选可能隐藏相邻商品，建议排序时清空搜索和状态筛选。
- **回收站**：点击“移入回收站”并确认；商品从正常列表隐藏。顶部“查看”选“回收站”，点击“恢复商品”。状态、售价、照片和置顶信息保留。没有永久删除原图功能。
- **发布前检查**：显示“可以发布／需要完善／存在错误”，逐项说明问题。“可以发布”仅代表通过本机检查，正式发布一直关闭。下架/售罄和演示商品会有提示，不将其当成待上架真商品。

## 旧水印怎样升级

新上传图自动永久嵌入多处分布式“扎西德勒鸭”和两个真实客服微信号，保持原比例与实物，不使用AI。透明度、倾斜角、颜色和客服信息沿用品牌全局配置。原图文件不改变。

V1.4.0的右下角水印图仍能读取，不会在启动时被强制重写。发布前检查会提示需要升级；点击 **备份并升级旧照片水印**，确认后先在私有目录生成完整ZIP，完成后再从对应原图生成分布式保护图，切换当前关联。旧原图、旧展示图和历史版本全部保留。过程可能需要几分钟，请保持服务和页面开启；失败时当前关联不切换，成功生成但未使用的文件保留，不误删原图。

升级前ZIP可在“备份与恢复 → 已生成的完整ZIP”下载。没有私有原图或文件损坏时会停止；请用完整备份恢复或补回真实原文件，不能用水印图冒充原图。旧顾客端已经确认的VI图片保持原样，不在此轮重新处理。

## 建议验收顺序

1. 核对已有资料，生成并另存完整ZIP。
2. 新增一条明确命名的测试商品，上传多张实拍，设封面、调顺序，保存后重启核对。
3. 设置两个款式，不同照片、价格和状态，点“预览”逐款核对。移除照片先点“取消”，再确认；核对原照片仍在已上传照片库。
4. 同分类新增两条测试商品，练习上移/下移、置顶；刷新后检查顺序。
5. 将测试商品移入回收站（先取消一次），再恢复，检查照片及款式信息完整。
6. 点击发布前检查，检查缺图提示和旧水印升级；原图齐全时可先备份再确认升级。
7. 再生成完整ZIP，修改一项测试资料，从ZIP校验并确认恢复，核对恢复的是整个库而非合并商品。历史快照和原JSON资料备份仍可用。
8. 打开顾客网站核对保持原样；后台在售、售罄或排序都不会同步出去。

## 数据安全与回退

- 数据格式保留schemaVersion 1，款式售价/状态、置顶和回收站为兼容的可选字段；旧资料未填写时沿用旧行为。每次保存前后保留历史快照。
- 首次写入前自动建立`upgrade-1.4.1`资料基线。管理台可下载“V1.4.1升级前资料”。它是资料备份，照片仍需完整ZIP保护。
- 完整ZIP包含商品、分类、款式价格/状态、排序、回收站、关联、登记原图/展示图和历史快照；旧版ZIP和资料备份可在新版恢复。无原图的旧展示图仍明确提示缺失，不伪造恢复。
- 旧V1.4.0程序不理解新分布式照片登记或回收站语义。升级后不要用旧程序同时编辑同一个库。需要回退时先保存完整ZIP，由维护人员协助恢复升级前资料，再运行旧版；直接换程序不是完整业务回退。
- 原图、旧展示图、历史版本均不自动清理，会多占本地空间；保持足够空闲空间，备份另存外置磁盘。同机备份不能防硬盘/整机损坏，ZIP未加密，应按私有资料保管，不上传公开仓库。
- 图片仍支持JPG/PNG/WebP，单张25MB/4000万像素上限，不支持HEIC或动画；每批20张、每商品50张。全部照片只上传到本机后台，不发送外部服务器。
- 只监听127.0.0.1；管理授权网址不要分享。若失败，请提供安全错误编号及对应诊断记录，不要上传整个私有商品库。

没有新增付费依赖、云服务或账号要求。真实Windows文件权限/杀毒软件、首次组件安装和浏览器对话框仍需按此指南真机验收。
