## 按实际代码检查的起点

第一阶段有中文CRUD/搜索/款式/状态、仓库外schemaVersion 1不可变JSON快照、校验和、写入锁、JSON备份与确认恢复。本地旧照片只读复用，无照片上传/多图编辑/完整图片备份，无顾客端同步。本轮补齐缺少的照片及完整备份能力，不重建顾客网站。

## 完成内容

- Windows07自动准备免费组件后启动127.0.0.1管理台，授权会话、来源/CSRF校验沿用；无管理接口向局域网或公网开放。
- JPG/PNG/WebP多图二进制流式上传、进度/失败提示；私有资产记录SHA-256、原始字节、处理配方、缩略WebP/详情WebP/JPEG。使用现有Sharp和Fontkit，无AI、无收费API。
- 新照片按最新指令仅右下角一层中文品牌水印，字体自动随尺寸调整，轻微反差描边；原图不裁剪不修改，保持比例。既有顾客图片和旧水印不变。
- 以原图和配方指纹复用展示图，登记的受保护图片不能再次作为原图。排序、封面、公共/款式关联；移除只取消关联，成功上传的未引用资产永久保留并可重用。
- 默认编号/单位/款式、记忆分类、折叠选填资料，名称和价格必填；列表快速切换状态，保存中禁重复操作、失败回退，并发修改拒绝覆盖。
- 继续使用原私有目录、schemaVersion 1兼容字段；首次更改前保存可校验基线，不改变已有库。编辑/备份/恢复继续保留历史快照。
- 完整ZIP流式生成、进度、下载及重启后重新下载；含所有登记原图/保护图、关联、当前及历史资料、分类。校验路径、文件长度/SHA、图片元数据/关系、分类及历史格式；确认范围、校验后版本冲突拒绝、恢复异常回退并隔离保全被替换文件。
- JSON导出/恢复保留；新机缺照片的JSON不能冒充完整恢复；当前指针损坏仍可从有效ZIP或JSON恢复。
- 没有发布路由、没有顾客端数据写入；原03稳定通道保持，不覆盖第一阶段和V1.3.3代码。

## 风险、限制及维护

- 旧商品缺私有原图时明确提示，ZIP含已有受保护展示图及所有新登记原图，不能声称找回旧原图。补上传字节一致的真实原文件后可纳入备份。
- 不支持HEIC、动画、SVG；JPG/PNG/WebP覆盖常见电脑照片，尺寸与ZIP边界详见Windows说明。
- 未自动清理未引用照片/历史快照，避免不可逆误删；磁盘空间需定期查看。完整ZIP是未加密私有备份，需要另存外部磁盘，不能上传公开仓库。
- 外部未知水印无法可靠自动识别，必须上传原始实拍；已知系统输出和相同原图有明确防重规则。
- Windows真实CMD双击/网络安装/NTFS权限/保存文件夹对话框须真机验收；官方WASM回退已自动验证，不能代替所有Windows硬件测试。
- 管理新商品本地单品预览，不是顾客网站全站发布预览；顾客端发布/数据同步仍未开放，售罄/下架只是本地状态。
- 无新付费服务。新增MIT开源ZIP库yazl/yauzl，沿用免费Sharp/Fontkit/字体及本地磁盘；不需要服务器、数据库或账号费用。

[Windows操作说明](admin-phase2-windows.md)包含下载、新目录启动、备份及回退边界。main不合并、不部署、不更新正式网站。
