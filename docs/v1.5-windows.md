# V1.5.0 本地发布与款式库存：Windows更新和验收

## 更新与启动

1. 先保存未完成的后台编辑并关闭旧07窗口，再在原固定目录双击 **03-update.cmd**。沿用当前测试通道，不需要ZIP、不重新录入、不移动商品目录。
2. 双击同一更新目录的 **07-admin.cmd**，确认顶部 **V1.5.0 · 本地发布与库存测试版**。顾客网页仍由03自动启动或02打开localhost:3000，继续复用原网站。
3. 核对三款已保存商品及全部5款照片仍在。更新不会自动改价格/库存、清空或迁移商品库。

## 先用真实资料做无损验收

点击 **用已保存3款真实商品验收** 并确认。

它会按以下三个已保存名称读取5个款式：藏式吉祥金卡｜未开光版、藏式吉祥金卡｜开光版、迷你金属转经筒挂件；仅在本机私有临时副本测试发布、变价、库存2、库存0、撤回、重新发布及照片关联。原库的商品、价格、库存、发布状态和原图不改变，临时副本结束后清理。界面显示每项通过/失败，可复制报告。

若名称或5款资料不匹配、缺照片，会明确停止，不伪造实拍、不替换数据、不要求上传隐私图片。验证期间请暂停编辑。

这里无法读取用户电脑中的实物资料，所以开发环境的模拟测试不等于三款真实商品已验收。请实际运行此入口，并在顾客浏览器核对真实照片和PNG。

## 一次性启用本地发布管理

点击 **备份并启用本地发布管理**。

- 确认后先生成完整ZIP备份，再把当前在售、非演示、不在回收站的真实商品保留为初始发布版（包含已有三款，不重复录入）。原草稿及原图不改写。
- 失败时不切换当前展示数据。备份可在“备份与恢复 → 已生成的完整ZIP”下载到移动硬盘。
- 启用前保留V1.4.1本机兼容预览。**首次点保存草稿时如尚未启用，也会先请求确认并备份冻结现有版本，拒绝则不保存**，避免误把新草稿直接展示。
- 启用后，保存、变价、库存、照片、款式和回收站操作只改变草稿，不自动改顾客已发布版；撤回必须点击对应发布操作。

本轮所有“发布”都只到本机3000测试站，不是公网。正式网站发布按钮仍关闭，没有新增启动脚本。

03仅用于软件升级；日常商品发布不需要Git或上传ZIP。

## 日常最少步骤

1. 上传照片/编辑资料和各款库存，点 **保存草稿到本地**。
2. 点 **预览** 查看当前草稿名称、价格、款式图片和库存。
3. 点 **发布商品** 或 **更新已发布商品**，确认本机范围。
4. 刷新顾客网页查看发布结果。

列表会显示草稿、已发布到本机、有未发布修改、已撤回。点 **撤回发布** 后顾客刷新不再显示，草稿和照片仍保留。回收站中仍可撤回已发布商品；仅把草稿移入回收站不会代替发布撤回。

## 款式库存

展开颜色／款式，每款库存独立填写：

- 空白：未设精确库存，沿用状态销售，顾客需与客服确认。
- 0：该款显示“已售罄”，可查看实拍，不能加入清单；其他有库存款式不受影响。
- 正整数：顾客数量不能超过该款已发布库存，原单次清单99件上限保留。
- 加入/移除清单、生成PNG都不扣库存。管理员成交后手动改库存、保存草稿，再点更新发布才生效。

商品整体售罄/下架发布后会隐藏；款式下架隐藏，款式售罄或库存0会显示售罄。加入清单前检查发布版本和可用状态，旧页面发现更新会提示刷新，避免用旧价/已售罄库存继续加入。刷新会提示清单数量调整，售罄/撤回项移除，超库存数量缩减，不扣真实库存。

## 三款商品的浏览器验收

- 商品初始发布：逐件逐款核对真实名称、2/5/3元基础价（以实际资料为准）、实拍和介绍。
- 修改价格只保存草稿，顾客刷新应仍是旧价；更新发布后再刷新应为新价。请在确认后的测试范围操作，或只运行隔离验收工具，不随意改变真实商品价格。
- 某款库存先设2并发布，最多选2；设0但仅保存草稿，顾客仍是旧发布库存；更新发布后显示售罄且不可加入，其他款正常。
- 选不同款式加入，核对单价/数量/照片、金额及PNG；加入前后后台库存不变。
- 撤回一件后顾客刷新隐藏，后台资料/原图保留；再发布恢复。
- 完整ZIP备份后恢复，核对草稿、已发布版、库存、图片和状态。

## 数据安全和恢复

草稿与发布副本存于同一已校验、原子切换的商品快照中，避免“草稿成功、发布指针失败”造成不一致。发布检查照片及款式关系，成功前保留上一版本；每次更改前后历史快照及所有原图/旧展示图继续保留。

V1.5完整ZIP包含草稿、已发布副本、库存、状态、关联及全部登记原图/展示图和历史快照。恢复V1.5备份会恢复整个版本；恢复旧无发布信息的备份，只恢复草稿并保留当前已发布商品（包括必要的可管理记录），避免无意撤回。

若当前指针损坏且存在发布历史，旧无发布备份不会强行覆盖展示版，请选择含发布版本的V1.5备份或有效历史快照恢复。

旧版本程序不理解V1.5发布/库存语义，升级后勿同时用旧07编辑同一个库。空间上限仍按基础商品库8MB计算（含草稿与发布副本），超限明确停止，不覆盖旧数据。定期将完整备份另存外置磁盘；本机备份不能防硬盘损坏。
