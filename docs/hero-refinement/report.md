## 处理方法

1. 始终读取私有的原始门店照片，原文件摘要保持不变；不处理已经加水印的副本。
2. 以近处建筑边缘为参照，使用四点单应变换共同校正约1.4°水平倾斜与竖向偏斜。只双线性采样已有像素，边缘越界即报错，不扩图、不补画、不克隆货架或商品。保留货架向后延伸的真实透视，并非将所有不同深度的边缘强行拉平。
3. 校正后的有效区域为1480×1104；手机/缩略档按1.94:1、电脑档按2.15:1分别裁剪，去掉较多空白天花板并保留中央陈列柜与主过道。不拉伸、不改变页面主图容器比例。
4. 将敏感信息遮挡收紧到9个二维码/Wi-Fi区域。每个核心压成2×2色值，只保留极低频颜色平均，彻底移除原字符和二维码结构；核心100%替换，外侧12px渐变柔化。不是透明遮盖，也不只是对完整二维码轻度模糊。外围真实商品保留；渐变采用区域本身的颜色，不生成虚构物体。
5. 亮度仅提高2.5%，蓝通道白平衡微调0.4%，饱和度不增，轻度清晰化sigma0.35。保留真实暖色氛围，不改变品牌素材颜色。
6. 最后重新合成确认过的V1.1品牌标识、分布式半透明保护章和交替客服号；样式、品牌文件、全局透明度及角度不变，不叠加旧水印。

配置位于 `src/homepage.js` 的主图 refinement / masks；算法在 `scripts/hero-refinement.mjs`，由既有自动图片处理流程调用。若将来替换成不同拍摄角度的照片，需重新确认参照点及敏感区域，不能盲目沿用本图参数。
